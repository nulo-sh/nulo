# Phase 4: the windows and the slots

- The type-role inventory's reachability is lexical: a computed whose body calls a helper that reaches `trimAddress` makes every expression read from it an identifier site. Rows that carried their chips flagged the count line and the authorization node as sites. Fix: the chips moved to computeds of their own (`callChips`, `authwitChips`) bound with `v-bind` (D15).
- vue-tsc reads a JS component's slots as `{}`, so a `#name` slot on the JS identity block failed typecheck; the block moved to TS with `defineSlots` (D14).
- Vue's whitespace condensing drops a leading whitespace-only text node in a `<template>` branch, so a space before a chip inside a sentence is written `{{ " " }}`.
- vitest does not run the design resolver: a test mounting a component that uses `Popover`, `Icon`, `Flex` or `Text` registers them from `@nulo/design` through `global.components`.
