# Phase 6: lint and typecheck of `scripts/`

- **The probe drifted by the time the arc ran.** Biome over `scripts/` reformatted 39 files, not 38, and `interpretPreflight` scored 29, not 16-18 (F17 counted six functions over budget, which held). The warnings fell from 27 to 2 once the `noTemplateCurlyInString` override was in; the other 25 were all that rule.
- **Commit a reformat with the old Biome scope in place.** The pre-commit hook runs `biome check --staged` with the working tree's config; with `scripts/**` already included it lints the reformatted files and refuses on the seven errors the next commit fixes. Formatting under the widened config, then restoring the old `biome.json` for the reformat commit, keeps that commit to `scripts/` only and the hook honest.
- **A reformat can orphan a `biome-ignore`.** Wrapping a long line moved an `any` onto the line after its suppression (`behavior-gating.test.ts`), which Biome then reports twice: the unused suppression and the bare `any`. Move the comment onto the wrapped line.
- **`bun pm diff` is not a lockfile diff on Bun 1.4.2.** Run bare, it looks the root package up on npm (`404 Not Found: …/nulo`). An added dependency was reviewed through `git diff bun.lock`: `@types/bun` 1.4.2 and `bun-types` 1.4.2 (published 2026-09-05), with `typescript` 6.0.3 and `@types/node` reused from the lock.
- **`moduleDetection: "force"`** is what a Bun scripts tree needs: Bun runs every `.ts` as ESM, but tsc reads a file with no import or export as a script and refuses its top-level `await`.
- **`apps/extension/scripts/` had no typecheck at all** (the extension's `tsconfig.json` covers `src/` only, and `tsconfig.node.json` runs nowhere). A probe found three errors, so it is covered in this arc by `apps/extension/tsconfig.scripts.json`, chained into the extension's `typecheck`; it also reaches the Vite configs and, through imports, part of `tests/e2e/fixtures/`.
