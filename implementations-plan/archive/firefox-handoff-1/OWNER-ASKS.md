# firefox-handoff-1: owner asks

The page-79 record (P79-01 B) is the budget. **In the budget, worded by the owner before the PR leaves draft**: the three card copies (drafts: "Pick the contacts file", "Pick the account file", "Pick the backup file"; the line "Firefox closes the panel when a file picker opens, so the pick runs here."; Choose file; Cancel), the reopened panel, and the Cancel path, each pictured light and dark.

Beyond the record, each ask ships its "what ships now" form; the arc does not wait for an answer.

## OA-1: what the window shows after an account file or a backup file is picked

Surface: the Firefox hand-off window, Settings → Accounts → Import account and Restore again. The record says the contacts pick goes on through the selection list; these two have more steps after the file (the account: password, address preview, name, confirm; the backup: password, decrypt, restore, and Retry or View Errors when a network fails).
- **A (ships now)**: the card leaves and the page's next step shows in the same window, as today's window shows it. When the import ends the window closes itself and the panel opens on Accounts with "Account imported", or on Home with "<networks> restored" after a full restore (with no snack after Continue on a partial one). Picture: the account import page after a pick, in the window.
- Also in A: when Restore again finds nothing left to restore as the window opens (the reminder was dismissed or its networks deleted), the window closes itself before any press and the panel opens on Home with no snack, as the page leaves for Home today.
- B: the card carries the next steps itself (a new design for each flow).
- C: the card only for contacts; these two keep today's whole page.
- Recommendation: A. It reuses screens the person already knows, and the loop still closes.

## OA-2: Cancel, and the window's own close button

Surface: the hand-off window and the panel after it.
- **A (ships now)**: Cancel, or the back arrow after a pick, closes the window and the panel reopens on the page the pick started from, with no snack. The window's own close button (the OS one) closes it with nothing reopened; the next toolbar click opens Home.
- B: Cancel closes the window and nothing reopens.
- Recommendation: A. The person started in the panel; Cancel puts them back there.

## OA-3: a file refused before the import starts

Surface: the hand-off window, each of the three picks.
- **A (ships now)**: a file that is too large, holds no contacts or cannot be read shows its error snack over the card, and the card stays for another try. The selection list's own Cancel ends the flow: the window closes and the panel shows "Contact import canceled".
- Also in A: the account import and Restore again show their errors inline, so a refused account or backup file swaps the card for the page with its error and its own file row, as today's window shows it.
- B: any refusal also ends the flow, and the panel shows the error.
- Recommendation: A. A wrong file is fixed by picking again, which needs the card.

## OA-4: the profile restore from the panel

Surface: the lock screen's Import → Full Backup from Firefox's toolbar panel. It moves to a whole-page window today, for its passkey prompt as well as its file; the page-79 record names the three picks only.
- **A (ships now)**: unchanged.
- B: a fourth card for it.
- Recommendation: A until the owner asks. Its window shows a form (name, file, password), not the page the person was on, so the doubled-screen confusion does not apply.
