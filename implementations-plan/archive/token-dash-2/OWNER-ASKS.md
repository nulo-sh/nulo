# token-dash-2 owner asks

## OA-1: a blank symbol inside a sentence

- **Surface:** the places that put a stored or read token symbol inside a sentence, plus one label the lane brief does not list (recon § Render sites):
  - the transaction page's warning when the sent token is no longer in the list: "{symbol} is missing";
  - the token page's Home-is-full confirm: "Unpin one of these to pin {symbol}: …";
  - the token page's empty activity line: "Send or receive {symbol} to see activity here.";
  - Send's amount card, for a priced token or a clamped amount: "{symbol} supports N decimals", "1 {symbol} ≈ $…" and the "Type in {symbol}" hint; and its unit toggle "{symbol} / USD", a label, shown only for a priced token (so only a token on the signed price list whose contract returns a blank symbol);
  - the Allow sheet for an unlisted incoming token: "Allow {symbol}?" (its symbol comes from the incoming record, not a stored token).
- **Why it comes up:** P72-05 C gives the dash to names, titles and labels. With a blank symbol these sentences show a gap ("   is missing"). A dash there ("— is missing") reads like a dash joining two clauses, which the house copy rules avoid.
- **Options:**
  - A. As today: the gap stays.
  - B. The dash, as on names and titles ("— is missing", "Allow —?").
  - C. A noun in place of a blank symbol ("This token is missing", "Allow this token?"), with each sentence's wording yours.
- **Recommendation:** C, worded per sentence, in a later lane with its own pictures; B for the unit toggle, a label. B reads like a clause join in a sentence; A is the gap #932 reports.
- **What ships now:** A. These sentences and the toggle do not change.
- **Blocks arc 1:** no. Filed as #949 (`owner-decision`).
